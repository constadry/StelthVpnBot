Обнови файл `DOCS.md` в корне проекта, задокументировав последнее изменение.

Шаги:
1. Посмотри `git diff HEAD~1 HEAD --stat` чтобы понять какие файлы изменились
2. Посмотри `git log -1 --pretty="%s%n%b"` чтобы взять описание из коммита
3. Прочитай текущий `DOCS.md` (если существует)
4. Добавь новый раздел в начало файла в формате:

```
## [дата] — <название фичи/фикса>

**Что изменилось:** одно предложение

**Затронутые файлы:** список файлов

**Использование** (если есть новые команды/API):
- `/команда` — что делает

**Детали:** краткое техническое описание если нужно
```

5. Сохрани `DOCS.md`

Не создавай отдельных файлов — всё в один `DOCS.md`. Пиши по-русски. Будь кратким — максимум 10 строк на раздел.
